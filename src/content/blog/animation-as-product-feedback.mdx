## Motion should explain what changed

Interface animation is most valuable when it helps someone understand cause and effect. A panel expands from the control that opened it. A saved item settles into its new position. A theme grows from the button that changed it. These transitions connect an action with its result.

Good motion is brief, spatially consistent, and interruptible. It should never make a person wait for the interface to become useful. The movement supports the state change rather than becoming the main event.

## Timing is part of the interaction

An animation can be visually polished and still feel wrong when its timing is detached from the underlying work. Coordinate related elements from the same progress value and keep the final state available even when an animation is skipped. This turns motion into dependable product feedback instead of decoration.
